## 一、项目概述

用 ESP32-S3-N16R8 开发板驱动一辆四轮差速小车，手机浏览器通过 Wi-Fi 连接后，用网页摇杆遥控行驶；HC-SR04 超声波传感器测量车头前方距离，当距离 < 20 cm 时自动拦截前进指令；ST7789 IPS 屏幕实时显示当前动作、前方距离和热点信息。

## 三、功能说明

### 3.1 Wi-Fi 热点
- 开机即启动 AP 模式（SoftAP），无需路由器
- **SSID**: `4WD-Car`，**密码**: `12345678`
- IP 固定为 `192.168.4.1`

### 3.2 网页遥控界面
- 访问 `http://192.168.4.1` 打开控制页面
- 页面布局：**上方状态栏**（当前动作 + 前方距离），**中央摇杆**
- 摇杆采用虚拟圆形摇杆，支持触摸和鼠标拖拽
- 松手后摇杆回中，发送停止指令

### 3.3 差速控制逻辑
- 摇杆 Y 轴（上/下）控制基础前进/后退速度
- 摇杆 X 轴（左/右）控制左右轮差速，实现转向
- 公式：
  ```
  leftSpeed  = Y + X   (clamp to [-255, 255])
  rightSpeed = Y - X   (clamp to [-255, 255])
  ```
- PWM 范围 0–255（8-bit）

### 3.4 障碍物保护
- HC-SR04 以约 100 ms 为周期轮询测距
- 当前方距离 < **20 cm** 时，**拦截所有前进分量**（leftSpeed > 0 且 rightSpeed > 0 时置零）
- 后退、转向（差速）仍然有效
- 屏幕和网页状态栏均提示"前方障碍"

### 3.5 断线保护
- 使用 WebSocket 通信；当连接断开时（`ws_client_count() == 0`），立即令所有电机停止
- 额外的 **500 ms 超时**保护：即使 WS 连接存在，若 500 ms 内未收到新指令，电机同样停止（防止网页卡住时车失控）
- 网页端每 100 ms 发送一次心跳指令，保持连接活跃


### 3.6 屏幕显示内容
| 区域 | 内容 | 字号 | 颜色 |
|------|------|------|------|
| 标题行（y=8）| `4WD CAR` | 大（×3）| 青色 |
| WiFi 行（y=56）| `WIFI:4WD-Car` | 中（×2）| 白色 |
| IP 行（y=80）| `IP:192.168.4.1` | 中（×2）| 白色 |
| 客户端行（y=104）| `CLIENT:ON` / `CLIENT:OFF` | 中（×2）| 绿/红 |
| 距离行（y=140）| `45 CM` / `-- CM` | 超大（×4）| 黄色（障碍时红色）|
| 动作行（y=184）| `FWD` / `BACK` / `LEFT` / `RIGHT` / `STOP` / `BLOCKED` | 中（×2）| 绿色 |
| 状态行（y=208）| `OK` / `OBSTACLE!` | 中（×2）| 绿/红 |

## 四、硬件接线

### 4.1 GPIO 分配总表

| 功能 | 信号 | GPIO |
|------|------|------|
| ST7789 SPI CLK | SCL | GPIO 12 |
| ST7789 SPI MOSI | SDA | GPIO 11 |
| ST7789 片选 | CS | GPIO 10 |
| ST7789 数据/命令 | DC | GPIO 9 |
| ST7789 复位 | RST | GPIO 8 |
| ST7789 背光 | BL | GPIO 7 |
| TB6612 左侧 PWM | PWMA | GPIO 1 |
| TB6612 左侧方向 1 | AIN1 | GPIO 2 |
| TB6612 左侧方向 2 | AIN2 | GPIO 3 |
| TB6612 右侧 PWM | PWMB | GPIO 4 |
| TB6612 右侧方向 1 | BIN1 | GPIO 5 |
| TB6612 右侧方向 2 | BIN2 | GPIO 6 |
| TB6612 使能 | STBY | GPIO 45 |
| HC-SR04 触发 | TRIG | GPIO 46 |
| HC-SR04 回波 | ECHO | GPIO 14 |

> **注意**：原方案 ECHO 用 GPIO 0，但 GPIO 0 是下载模式 strapping 脚，分压电阻的 2kΩ 下拉会让它在复位时为低电平，导致开发板每次复位都进下载模式，因此改为 GPIO 14。

### 4.2 ST7789 屏幕接线

| 屏幕引脚 | 接到 |
|---------|------|
| GND | GND |
| VCC | 3.3 V |
| SCL | GPIO 12 |
| SDA | GPIO 11 |
| RST | GPIO 8 |
| DC | GPIO 9 |
| CS | GPIO 10 |
| BL | GPIO 7（高电平点亮）|

### 4.3 TB6612FNG 接线

| TB6612 引脚 | 接到 |
|------------|------|
| VM | 电机电池正极（6–15 V）|
| VCC | 3.3 V（逻辑电源）|
| GND | 公共地（开发板 GND + 电池负极共地）|
| STBY | GPIO 45（需拉高才能工作）|
| PWMA | GPIO 1 |
| AIN1 | GPIO 2 |
| AIN2 | GPIO 3 |
| AO1, AO2 | 左前电机 + 左后电机（并联）|
| PWMB | GPIO 4 |
| BIN1 | GPIO 5 |
| BIN2 | GPIO 6 |
| BO1, BO2 | 右前电机 + 右后电机（并联）|

> **电机电源与开发板务必共地，但电机电源不向开发板 5V/3.3V 引脚供电。**

### 4.4 HC-SR04 接线

| HC-SR04 引脚 | 接到 |
|-------------|------|
| VCC | 5 V（从开发板 5V 引脚或独立 5V 取）|
| GND | 公共地 |
| TRIG | GPIO 46 |
| ECHO | GPIO 14（需串 1kΩ + 2kΩ 电阻分压降至 3.3V）|

> **电平转换**：HC-SR04 ECHO 输出为 5V，ESP32-S3 GPIO 最高耐受 3.3 V。  
> 方案：ECHO → 1kΩ → GPIO 14，GPIO 14 → 2kΩ → GND（分压后约 3.3V）。

## 五、软件架构

### 5.1 开发框架
- **ESP-IDF v6.1**（`idf.py` 命令行构建，由 `build.sh` 封装）

### 5.2 使用的 IDF 组件

| 组件 | 用途 |
|------|------|
| `esp_wifi` / `esp_netif` | SoftAP 热点 |
| `esp_http_server`（含 WebSocket）| 提供控制页面（`/`）和实时通道（`/ws`）|
| `esp_lcd`（`esp_lcd_new_panel_st7789`）| ST7789 SPI 屏幕，自带 5x7 字体按行重绘 |
| `driver/ledc` | 电机 PWM（20 kHz，8 位）|
| `driver/gpio` | 方向引脚、HC-SR04 边沿中断测距 |

### 5.3 任务划分（FreeRTOS）

```
control_task    (20ms)   摇杆值 + 障碍联锁 + 失联超时 -> 差速电机输出
ultrasonic_task (100ms)  触发 HC-SR04，ECHO 边沿中断计时，更新距离
ui_task         (200ms)  通过 WebSocket 上报状态 + 刷新屏幕（仅内容变化的行重绘）
esp_http_server 内部任务  处理 HTTP / WebSocket 收包
```

### 5.4 WebSocket 消息格式

**手机 → 开发板**（JSON）：
```json
{"x": 0.5, "y": -0.3}
```
- `x`、`y` 范围 `[-1.0, 1.0]`，对应摇杆偏移量归一化值

**开发板 → 手机**（JSON，每 200ms 推送）：
```json
{"action": "前进", "dist": 45, "blocked": false}
```
- `action`：当前动作中文名
- `dist`：前方距离（cm），量程外为 `-1`
- `blocked`：是否处于障碍拦截状态（网页据此显示红色警告条）

## 六、构建与烧录流程

1. 确认已安装 ESP-IDF v6.1（默认路径 `~/esp/esp-idf-v6.1`）。
2. 编译：
   ```bash
   ./build.sh
   ```
3. 烧录（USB 连接开发板，自动探测 `/dev/cu.usbmodem*`）：
   ```bash
   ./build.sh flash
   ```
4. 查看串口日志：`./build.sh monitor`

> 项目根目录下的 `build.sh` 封装了 export.sh + idf.py，一键完成编译+烧录。
